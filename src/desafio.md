Desafio — useState + contador

Crie um componente React que tenha:

Um número inicial 0.

Botão Incrementar → soma 1.

Botão Decrementar → subtrai 1.

Botão Resetar → volta para 0.

O contador não pode ficar abaixo de 0.

Regra: use apenas useState para controlar o estado.
Bônus: mostre uma mensagem diferente quando o contador chegar a 10.
